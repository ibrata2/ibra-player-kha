# Ibra Player Kha

مشغّل صوت وفيديو للموبايل **بدون إعلانات**، خفيف وبواجهة زجاجية عربي/إنكليزي، وبيه قسم **تحميل من يوتيوب**: تختار صوت (MP3 320/192/128 أو M4A الأصلي) أو فيديو بالدقة اللي تريدها (من 144p إلى 4K حسب الفيديو).

- أزرار جاهزة تفتح يوتيوب ومواقع الأغاني (YouTube Music، SoundCloud، Audiomack، Bandcamp، Mixcloud) داخل التطبيق، تفتح الأغنية وتضغط «تحميل».
- أو شارك أي رابط من تطبيق يوتيوب ← **Ibra Player Kha** والرابط يفتح بقسم التحميل مباشرة.
- التحميلات تنحفظ بـ `Download/Ibra Player Kha` وتطلع وحدها بمكتبة الموسيقى والفيديو.
- أداة التحميل (yt-dlp) تتحدث وحدها مرة باليوم، وبيها زر تحديث يدوي.
- تحديثات التطبيق من داخل التطبيق.

## التنزيل
من صفحة [Releases](../../releases/latest):
- `arm64` ← أغلب الموبايلات الحديثة.
- `armv7` ← الموبايلات القديمة.

## البناء
كل دفعة على `main` تبني الـAPK تلقائياً بـ GitHub Actions وتنشره بـ Releases.
